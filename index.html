TLF App

Dán link Web app TLF của bạn (link kết thúc bằng /exec).

  1. Mở Apps Script của TLF → Deploy → Manage deployments.
  2. Sao chép Web app URL rồi dán vào ô trên.

Chưa có mạng

TLF cần Internet để lấy dữ liệu từ Google Sheets của bạn. Kiểm tra Wi-Fi hoặc 4G rồi thử lại.
